How to Call the Dog CEO API

Step 1 — The URL is the request

What I did: I entered the Dog CEO API URL into my browser.
What I saw: The API sent back JSON containing a dog image URL (a mountain bernese) and a success status. 

{
        "message": "https://images.dog.ceo/breeds/mountain-bernese/n02107683_3278.jpg",
        "status": "success"
      }

JSON Organizes the API Response

Today I learned that an API can send its response back as JSON. The JSON response from the Dog CEO API gave me a message property containing the image URL and a status property showing that the request was successful. 

{
        "message": "dog image URL",
        "status": "success"
      }

Status Codes Tell Me What Happened

Today I learned that a status code tells me how an API request went. A 200 status code means my request was successful, while a 400 can mean something is missing or incorrect in my request. 


      200 OK
      400 Bad Request
      404 Not Found

API Keys Need to Stay Private

I learned that an API key identifies my account when I send a request. Instead of putting the key in the URL, I sent it through a header in Postman and used a variable so the actual key did not have to appear in the request. 

X-Api-Key: {{api-key}}

Parameters and Arguments

Today I learned that a parameter is a variable used by a function. An argument is the actual value I give the function when I call it. 

function describe(cat) {
  console.log(cat.name);
}

describe(pets[0]);

Reading One Cat Record

I learned that JavaScript can read individual properties from an object using dot notation. This lets my function take one cat record and use specific information such as its name and origin. 

function describe(cat) {
  console.log(cat.name + " is from " + cat.origin);
}

describe(pets[0]);
